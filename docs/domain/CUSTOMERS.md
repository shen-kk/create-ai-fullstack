# 用户端账号

## 定义

`Customer` 表示使用产品用户端的注册用户，与后台 `User`（管理员数据模型）是不同身份。

## 不变量

- 手机号是必填、规范化后的唯一登录标识。
- 邮箱和头像是可选资料，不参与默认登录。
- 密码只保存 scrypt 哈希；API 和日志不得返回密码、哈希或 Refresh Token。
- 停用用户不能登录、刷新会话或访问受保护的用户端接口。
- Refresh Token 只存在于 `customer_refresh` HttpOnly Cookie，轮换后旧会话立即失效。
- 用户端 Access Token 的 `audience` 必须为 `customer`，不得被后台权限守卫接受。
- 用户注册、资料修改与密码修改必须进入审计日志，审计元数据不保存敏感值。
- 后台停用用户端账号时必须撤销全部刷新会话；Access Token 每次鉴权重新加载启用状态。

## 当前能力

- 手机号验证码、密码、称呼及可选邮箱注册。
- 手机号密码/验证码登录、会话恢复、安全退出和短信找回密码。
- 修改称呼、头像地址和密码；邮箱变更必须通过验证码绑定。
- 后台按关键词和状态分页查询用户，并执行启用/停用管理。

验证码按用途隔离，5 分钟过期、60 秒重发限制、最多错误 5 次，成功后立即消费；只保存目标和验证码摘要。开发内存模式可回显测试码，生产禁止回显。第三方登录和账号注销留待具体产品选择。
