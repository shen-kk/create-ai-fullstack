# 用户端账号

## 定义

`Customer` 表示使用产品用户端的注册用户，与后台 `User`（管理员数据模型）是不同身份。

## 不变量

- 手机号与邮箱由后台认证策略二选一作为登录标识；二者分别唯一，账号至少拥有其中一个。
- 头像是可选资料，只能通过已绑定的对象存储上传，不接受手工 URL 或本地文件兜底。
- 密码只保存 scrypt 哈希；API 和日志不得返回密码、哈希或 Refresh Token。
- 设置、登录、修改和找回密码统一要求至少 6 个字符。
- 停用用户不能登录、刷新会话或访问受保护的用户端接口。
- Refresh Token 只存在于 `customer_refresh` HttpOnly Cookie，轮换后旧会话立即失效。
- 用户端 Access Token 的 `audience` 必须为 `customer`，不得被后台权限守卫接受。
- 用户注册、资料修改与密码修改必须进入审计日志，审计元数据不保存敏感值。
- 后台停用用户端账号时必须撤销全部刷新会话；Access Token 每次鉴权重新加载启用状态。

## 当前能力

- 首次验证码登录自动创建账号，不提供独立注册页。
- 按后台选定的手机号或邮箱完成密码/验证码登录、会话恢复、安全退出和找回密码。
- 修改称呼、上传头像和设置/修改密码；联系方式变更必须通过验证码绑定。
- 后台按关键词和状态分页查询用户，并执行启用/停用管理。
- 用户可以查看有效 Refresh Session 的脱敏设备信息，撤销单个会话或保留当前设备并退出其他设备。
- 后台可以按渠道、用途和状态查询验证码发送记录；记录只包含脱敏目标、结果、错误码和错误尝试次数。

验证码按用途隔离，5 分钟过期、60 秒重发限制、最多错误 5 次，成功后立即消费；只保存目标和验证码摘要。验证码必须经已启用的短信或邮件服务真实发送，API 不回显验证码。第三方登录和账号注销留待具体产品选择。
