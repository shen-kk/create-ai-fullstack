# 业务词汇表

所有团队成员和 AI 使用同一术语。新增业务概念时先在此定义，避免同义词漂移。

| 术语     | 定义                                             | 禁用别名               |
| -------- | ------------------------------------------------ | ---------------------- |
| Admin    | 使用内部后台的运营人员；对应后台 `User` 数据模型 | 普通用户、Customer     |
| Customer | 使用用户端产品的注册用户；不拥有后台权限         | Admin、后台用户        |
| API      | `apps/api` 暴露的 HTTP 服务                      | 后端接口层（含义模糊） |

具体业务领域建立独立文件，并记录状态、状态转换、权限和不可破坏的不变量。
