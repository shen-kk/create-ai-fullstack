# Admin 开发规范入口

Admin 是内部运营工具，目标是高信息密度、清晰层级、稳定操作和可审计，不追求用户端的品牌化动效。

## 必读路由

- 视觉与布局：`docs/admin/DESIGN_SYSTEM.md`
- 基础组件与页面模式：`docs/admin/COMPONENTS.md`
- 新功能流程：`docs/admin/FEATURE_GUIDE.md`
- API 与状态：`docs/admin/STATE_AND_API.md`

Admin 不复用 Web 的 shadcn-vue 组件和视觉 Token。两端可以共享 contracts、错误码中文映射原则和可访问性底线。
