# Admin Design System

## 设计目标

- 大气但克制，优先可扫描性和操作效率。
- 高分辨率桌面使用侧边栏外全部可用宽度，不把内容限制在狭窄居中容器。
- 页面标题、筛选区、数据区和操作区形成稳定层级。

## 默认规则

- 使用 Admin 自己的颜色、间距、圆角、阴影和层级 Token，不引用 Web Token。
- 常规控件高度采用统一规格；紧凑表格场景只能通过组件 `size` variant 调整。
- 侧边栏按系统管理、用户运营等领域分组，图标统一线性风格。
- 状态默认显示中文；颜色只是辅助信息，必须同时显示文字。
- 动效仅用于弹窗、菜单和状态切换，保持短且一致，不使用营销型滚动动画。
- 高风险操作使用明确确认，危险按钮不能只靠红色表达含义。

## 弹窗

- 点击遮罩不关闭；头部和底部固定，仅内容区域滚动。
- 内容滚动条贴最右侧，外框上下不制造空白带。
- 宽度使用 `sm/md/lg/xl` variant；长表单优先宽布局和字段分组。
- 打开时焦点进入弹窗，关闭后返回触发按钮，并支持 Escape。
