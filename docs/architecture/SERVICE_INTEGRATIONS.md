# 外部服务接入登记

本文件只记录服务类型、配置名称和接入条件，不保存账号、密码、Token、主机地址或其他凭据。

## 当前已对应

### PostgreSQL

- 状态：模板已定义，Prisma 使用 `DATABASE_URL`。
- 配置位置：本地 `.env` 或部署平台密钥管理服务。
- 禁止：把真实数据库连接串写入 `.env.example`、Prisma schema、文档或日志。

## 待功能需要时接入

### Redis

- 接入条件：实现限流、缓存、队列或可撤销会话存储时。
- 当前登录限流采用单实例内存计数，仅用于开发与模板基线；生产多实例部署必须改用 Redis 等共享存储。
- 建议配置：`REDIS_URL`。
- 接入后必须增加连接就绪检查、超时、重试上限和不可用降级策略。

### SMTP 邮件

- 接入条件：实现邮箱验证、密码重置或通知邮件时。
- 建议配置：`SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASSWORD`、`MAIL_FROM`、`MAIL_TEMPLATE_ID`。
- 模板内容进入源码或模板文件；SMTP 密码只能进入密钥管理服务。

### 短信服务

- 接入条件：产品明确需要手机号验证或短信通知时。
- 建议配置：`SMS_PROVIDER`、`SMS_API_BASE_URL`、`SMS_API_TOKEN`。
- 必须实现发送频率限制、验证码摘要存储、短有效期和防重放。

### 支付服务

- 接入条件：具体业务领域确认订单、金额、退款和对账规则后。
- 建议配置：`PAYMENT_PROVIDER`、`PAYMENT_API_BASE_URL`、`PAYMENT_MERCHANT_ID`、`PAYMENT_API_KEY`、`PAYMENT_WEBHOOK_SECRET`。
- 必须验证回调签名、使用幂等键、以服务端金额为准，并记录可审计的状态转换。

## 密钥处理规则

- `.env.example` 只提供无效占位值。
- 本地真实值只放在已被 Git 忽略的 `.env`。
- 生产值放在部署平台或专用密钥管理服务。
- 禁止在聊天、工单、截图、Office 文档、测试数据和日志中传递明文密钥。
- 任何曾以明文出现在文档或聊天中的密钥均视为已泄露，必须在对应服务控制台轮换。
