# 外部服务接入登记

## 服务资源库（当前规则）

- 服务配置是固定类型的资源库，不再由初始化向导逐项询问是否启用。
- 固定类型包括：SQL、Redis、对象存储、短信、邮件、支付、Linux 服务器和 Git 仓库。
- 同一类型可以创建多个命名资源，例如“测试数据库”“正式数据库”“测试服务器”。
- 资源支持编辑和删除；被系统功能绑定或被部署环境引用的资源禁止删除，必须先解除绑定或替换引用，避免运行时配置悬空。
- `pnpm setup` 收集项目启动必需的 PostgreSQL并创建“开发数据库”资源；选中验证码功能时可选配置开发 Redis，其余资源在后台按需创建。
- 业务功能或部署环境只保存资源 ID，执行时由 API 读取并解密资源，再生成运行参数。不得把密钥复制到前端或项目声明文件。
- 系统功能通过稳定功能编码绑定资源，例如后台头像、用户头像、注册/登录/找回密码验证码。绑定资源必须启用且类型匹配；禁止按创建顺序自动选择资源，未显式绑定时对应功能不可用并返回稳定配置提示。
- 新版运行时能力必须显式绑定服务资源；旧版单例配置仅用于兼容尚未迁移的调用，不作为功能绑定的默认值。
- 用户端认证方式由独立策略配置控制，只允许手机号或邮箱二选一。用户端不提供独立注册页，首次验证码登录会自动创建账号并登录；启用认证方式前，登录和找回密码对应的短信或邮件功能必须显式绑定资源。
- 功能绑定按 API 返回的分组信息展示：用户端认证组根据当前认证方式动态显示短信、邮件或两类绑定；头像上传等不随认证方式变化的能力进入公共功能组。新增功能应在服务端目录登记分组，不在页面硬编码分组名单。

本文件只记录服务类型、配置名称和接入条件，不保存账号、密码、Token、主机地址或其他凭据。

## 当前已对应

### PostgreSQL

- 状态：模板已定义，Prisma 使用 `DATABASE_URL`。
- 配置位置：本地 `.env` 或部署平台密钥管理服务。
- 禁止：把真实数据库连接串写入 `.env.example`、Prisma schema、文档或日志。

## 待功能需要时接入

### Redis

- 接入条件：实现限流、缓存、队列或可撤销会话存储时。
- 当前登录限流采用单实例内存计数，仅用于开发与模板基线；生产多实例部署必须改用 Redis 等共享存储。
- 建议配置：`REDIS_URL`。
- 接入后必须增加连接就绪检查、超时、重试上限和不可用降级策略。

### SMTP 邮件

- 接入条件：实现邮箱验证、密码重置或通知邮件时。
- 建议配置：`SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASSWORD`、`MAIL_FROM`、`MAIL_TEMPLATE_ID`。
- 模板内容进入源码或模板文件；SMTP 密码只能进入密钥管理服务。
- 已实现通用 TLS SMTP 与腾讯云 SES API 验证码发送；非 TLS SMTP 明确拒绝。腾讯云、阿里云等厂商提供的标准 SMTP 均使用“通用 SMTP”，不重复建立厂商选项。腾讯云 SES API 使用 SecretId、SecretKey、发件地址和已审核模板 ID，模板数据传递 `code` 与 `minutes`；其他厂商 API 适配器由具体项目按需新增。
- 消息内容由独立 `MessageTemplate` 管理，功能绑定同时选择服务资源和消息模板。SMTP 使用标题与正文模板；SES API 和短信使用服务商模板 ID 与参数映射。支持 `code`、`minutes`、`projectName`、`purpose` 四个受控变量，未绑定模板时拒绝发送，不默认选择第一条模板。

### 短信服务

- 接入条件：产品明确需要手机号验证或短信通知时。
- 建议配置：`SMS_PROVIDER`、`SMS_API_BASE_URL`、`SMS_API_TOKEN`。
- 必须实现发送频率限制、验证码摘要存储、短有效期和防重放。
- 已实现腾讯云短信 TC3 签名适配；后台需配置 SecretId、SecretKey、短信应用 AppID、签名和模板 ID。

### 支付服务

- 接入条件：具体业务领域确认订单、金额、退款和对账规则后。
- 建议配置：`PAYMENT_PROVIDER`、`PAYMENT_API_BASE_URL`、`PAYMENT_MERCHANT_ID`、`PAYMENT_API_KEY`、`PAYMENT_WEBHOOK_SECRET`。
- 必须验证回调签名、使用幂等键、以服务端金额为准，并记录可审计的状态转换。

## 密钥处理规则

- `.env.example` 只提供无效占位值。
- 本地真实值只放在已被 Git 忽略的 `.env`。
- 生产值放在部署平台或专用密钥管理服务。
- 禁止在聊天、工单、截图、Office 文档、测试数据和日志中传递明文密钥。
- 任何曾以明文出现在文档或聊天中的密钥均视为已泄露，必须在对应服务控制台轮换。
