# 安全基线

- 任何权限判断都在 API 执行；前端权限仅改善体验。
- 密钥只来自环境或密钥管理服务，不进入 Git、日志、客户端 Bundle 或错误响应。
- 默认启用 DTO 白名单并拒绝未知字段，输出只返回显式定义字段。
- 密码使用成熟的自适应哈希算法；令牌、Cookie 与 CSRF 策略需通过身份认证 ADR 确认。
- 敏感操作记录操作者、对象、时间与结果，但不得记录密码、完整令牌和不必要的个人数据。
- 依赖更新、文件上传、富文本、跳转 URL 和 Webhook 都视为安全边界。
- 安全规则需要测试失败路径，不能只依赖代码评审。
- 外部服务的配置名、接入条件和密钥处理规则见 `SERVICE_INTEGRATIONS.md`。
- Office 文档、聊天记录和截图不是密钥存储介质；其中出现的真实凭据必须立即轮换。
