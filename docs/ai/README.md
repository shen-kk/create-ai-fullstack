前端调用 API 时必须保留稳定错误码并映射为中文提示，禁止所有提交失败统一显示无上下文的“保存失败”。弹窗内容可以滚动，但标题栏和操作栏必须保持固定，避免用户失去上下文或误触提交。

项目记忆分为四层：

- `AGENTS.md`：强制执行的工作规则和目录边界。
- `HANDOFF.md`：新 AI 的快速交接入口，记录当前完成度、真实缺口和下一步顺序。
- `CONTEXT.md`：当前有效事实和文档路由，不存流水账。
- `docs/domain`：业务词汇、规则、状态和不变量。
- `docs/decisions`：重要选择及原因，避免后续反复推翻。

当实现改变事实时，同一次提交更新相应记忆。过期信息应直接修正或删除，不在正文保留历史版本；历史原因交给 Git 与 ADR。

新接手项目时先读 `HANDOFF.md`，再按其中的最小阅读集加载相关文件，避免无目的遍历仓库。

不要写入密钥、个人信息、生产数据、短期调试结论或未经确认的猜测。
