> 本文件用于记录具体项目的 Web 视觉方向。模板仓库保持 `pending`；生成项目第一次进行 Web 页面或组件开发时，由 AI 在询问用户后更新。不要记录临时讨论，只保留当前有效的设计决定。

## 首次开发门禁

当项目启用了 Web，且状态仍为 `pending` 时，AI 必须先暂停页面或组件实现，请用户描述期望的样式风格。至少需要确认：

- 整体风格与品牌气质；
- 偏好的颜色、明暗模式和页面密度；
- 可参考的网站、产品或设计稿（如有）；
- 明确不希望出现的视觉元素（如有）。

用户可以只给一句自然语言描述；信息不足但不影响方向时，AI 应整理合理默认值并请用户确认，不能擅自沿用模板 starter 的风格。确认后将状态改为 `confirmed`，把结果写入下方，再开始实现。

确认风格后的第一次 UI 实现必须覆盖所有仍会展示的既有 Web 界面，而不只是本次新增内容。AI 应审计并按已确认方向统一调整：首页、认证与找回密码、个人中心、Header、Footer、Toast、基础组件 variants、全局 Token 和动效。不能保留两套互相冲突的视觉语言；确实不需要的 starter 样式和组件应安全删除。

模板维护、纯业务逻辑、API、测试或不改变界面的修复不触发此门禁。
