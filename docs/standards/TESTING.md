# 测试与验收规范

## 测试分层

- 纯函数、状态映射、权限判断：单元测试。
- Service、Repository、数据库约束：集成测试，使用项目所有者提供的真实测试数据库。
- 登录、权限、关键写操作：API E2E。
- 跨端核心旅程：浏览器人工验收或稳定的端到端测试。
- Design System：组件状态页和关键视口视觉检查。

Bug 修复应先留下可复现测试。不能稳定自动化的视觉问题要记录复现路径、分辨率和截图。

## 必查状态

- 正常、空数据、加载、失败、重试、无权限；
- 重复提交、过期会话、网络超时；
- 移动端、常规桌面和高分辨率桌面；
- 键盘操作、可见焦点、减少动态效果；
- 中文状态映射和长文本溢出。

环境不可用时应明确标记“等待环境”，不得搭建未授权的本地替代服务或伪造测试通过。
