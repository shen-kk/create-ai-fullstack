# 数据库与迁移规范

- 模板默认只使用 PostgreSQL + Prisma，不提供 memory 模式或静默假数据回退。
- Schema 修改必须提交 migration；禁止只修改线上数据库或只运行 `db push`。
- Migration 迁移数据库结构和必要的兼容数据，不迁移环境密钥或普通业务数据。
- 只修改按钮等前端内容时不需要数据库迁移。
- 多表原子写入、状态竞争和余额类操作必须使用事务并说明隔离/并发策略。
- 列表必须稳定排序，分页默认 `createdAt desc, id asc`。
- 种子只创建系统权限、默认角色和显式初始化管理员，不制造演示业务数据。
- 删除策略、唯一约束、索引和数据保留周期由领域文档明确。
