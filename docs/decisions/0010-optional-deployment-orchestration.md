# ADR 0010：可选部署编排模块

## 状态

已接受。

## 决策

部署中心是初始化时显式选择的可选模块。Admin 负责配置与观察，API 负责权限、加密配置、任务状态和审计，Deploy Worker 负责 Git、远程构建、SSH、启动、健康检查和回滚。第一版 Worker 随 API 实例启动，但只在目标服务器执行构建；可通过 `DEPLOY_WORKER_ENABLED=false` 关闭消费，后续无需改变任务契约即可拆成专用进程。

部署能力面向通用 Git 和 Linux 服务器，不绑定 CNB。Git 凭据和 SSH 凭据使用 `CONFIG_ENCRYPTION_KEY` 加密保存，API 响应与日志只返回已配置字段名。每个环境同一时间只允许一个活动任务。

任务、步骤和日志写入 PostgreSQL；SSE 只承担实时传输，刷新页面后仍可恢复完整进度。部署采用不可变 release 目录和原子切换，应用回滚不自动回滚数据库。

## 原因

- 长时间构建和 SSH 命令不应占用 API 请求进程。
- 模板用户可能使用不同 Git 平台和多个部署环境。
- 持久化任务状态可支持断线重连、审计、失败诊断和回滚。
- 部署属于高权限、强副作用能力，不应成为所有新项目的默认依赖。

## 第一版边界

支持 Git HTTPS Token/SSH Key、Linux SSH 密码/私钥、Docker Compose、单服务器、分端部署、SSE 日志和应用版本回滚。不包含 Kubernetes、多服务器灰度、自动扩缩容和数据库自动降级。
