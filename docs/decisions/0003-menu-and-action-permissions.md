# ADR-0003：菜单权限与操作权限分层

- 状态：已接受
- 日期：2026-08-02

## 决策

- 权限使用同一稳定代码目录，但通过 `type=menu|action` 区分菜单可见性与业务操作。
- 菜单权限使用 `menu.<module>` 命名；操作权限使用 `<resource>.<verb>` 命名。
- `groupCode` 把同一业务模块的菜单和操作权限归组，供后台树形配置与审查。
- Admin 菜单与路由同时检查模块菜单权限；API 继续只按业务操作权限授权。
- 菜单权限只控制体验和导航，不得作为服务端数据安全边界。

## 结果

- 新增模块时必须同时判断是否需要菜单权限和操作权限。
- 系统角色权限随迁移/种子升级；自定义角色由后台配置。
- 权限代码不可在后台动态创建，避免无代码消费者的孤立权限。
