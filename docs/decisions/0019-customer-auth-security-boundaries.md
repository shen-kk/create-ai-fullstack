# ADR-0019：用户端认证安全边界修复

## 决策

- 验证码通过条件更新原子消费，同时校验未消费、有效期与最多五次尝试；并发失败不能绕过次数限制。
- 用户端密码登录在 DTO 边界统一去除账号首尾空格并转换邮箱大小写，限流与认证使用相同账号。
- 普通资料更新不再接受 `avatarUrl`，头像只通过既有上传端点写入。此项是对既定上传安全边界的修复；API 与 Web 必须一起发布，旧客户端发送该字段会收到白名单校验错误。响应中的头像字段保持不变。
- 找回密码时，在同一数据库事务内更新密码并撤销该用户所有已有会话，避免旧设备继续访问。
- 腾讯短信必须检查逐条发送结果，业务拒绝不得标记为发送成功。
- 后台 Access Token 每次请求读取当前有效身份与权限，停用和角色权限变更立即生效，不信任令牌内的旧权限快照。

## 验证

回归测试覆盖验证码并发消费与次数竞争、规范化账号限流、头像边界、密码重置撤销会话和短信业务失败。生产启动入口与实际构建路径保持一致。
