# ADR 0012：部署环境强制绑定资源

## 状态

已接受。

## 决策

部署环境创建或编辑时必须绑定 Git 仓库资源和服务器资源；部署项目变量声明 `sql` 或 `redis` 时，分别强制绑定 SQL 或 Redis 资源。环境表单不再提供未绑定资源时的仓库地址、令牌、SSH、数据库连接等备用字段。

服务器资源保存部署根目录模板（`deployRoot`）；环境绑定后自动带出该值，但由管理员在环境中填写实际部署路径（`deployPath`）。部署任务使用环境路径，历史任务仍使用已保存的不可变快照。

## 原因

- 避免同一环境存在资源表和环境字段两套密钥来源。
- 让资源校验、权限审计和脱敏逻辑集中在服务配置模块。
- 让项目环境页面只表达“绑定什么资源”，减少部署配置歧义。

## 兼容策略

旧环境记录的兼容字段暂时保留，供历史部署记录和迁移读取；API 新建/更新环境时不再接受未绑定资源作为替代方案，管理页面也不显示这些字段。后续清理旧列前，先完成历史记录归档与迁移验证。
