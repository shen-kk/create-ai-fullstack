# ADR-0014：受权限控制的敏感配置明文查看

## 状态

已接受。

## 决策

- 后台默认只显示敏感字段的掩码，不在资源列表或普通详情响应中返回明文。
- 新增独立操作权限 `secrets.read`，与服务编辑、部署管理权限分离。
- 具有该权限的管理员可通过字段后的眼睛按钮临时读取服务资源和部署环境中可逆加密的明文。
- 每次读取都写入审计日志，只记录资源、操作者、结果和字段名，不记录任何明文值。
- 无权限时保留眼睛入口，由 API 返回 403，Admin 显示明确权限提示。
- 管理员密码和用户密码仍使用不可逆哈希，任何权限均不能查看原密码；眼睛按钮只能查看当前输入框中尚未提交的内容。
- 加密密钥轮换后无法解密的历史数据不回显，要求管理员重新填写并保存。

## 影响

该能力提高运维可用性，同时扩大了高权限账号的数据暴露面。生产环境应严格限制 `secrets.read`，审计日志应纳入安全巡检，前端不得缓存明文到 localStorage 或日志。
