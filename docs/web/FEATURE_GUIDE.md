# Web 新功能开发指南

1. 明确用户旅程、入口、退出路径、认证要求和 SEO 属性。
2. 确认 API 与 contracts 已完成，不在 Web 复制服务端业务规则。
3. 先组合 `components/ui`，视觉增强再组合 `components/motion`。
4. 缺少基础组件时先补公共组件与状态示例，不在页面临时实现。
5. 覆盖首次加载、空态、错误、离线、会话过期、重复提交和成功反馈。
6. 验证 SSR 首屏、移动端、键盘操作、减少动态效果和中文排版。
7. 执行 `pnpm ui:check`、Web 类型检查、构建和相关测试。

营销展示与登录后业务区可以有不同页面密度，但必须共享同一套 Web Token 和基础组件。
